# /update — propose brain updates, user approves per item

1. Review what happened this session (git diff + conversation).
2. Propose list with reasons:
   - STATUS overwrite: now X, next Y
   - DECISIONS: confirm N entries (each needs rejected alternatives + source)?
   - MAP registration: new `topics/*` or `library/*` files?
   - HANDOFF needed? Only if switching.
   - PROJECT change? Almost never — discuss first.
   - Also list what you're NOT updating + why. No padding.
3. Wait for "ok all" / corrections / "skip". Then write. STATUS/HANDOFF write-then-announce, DECISIONS/PROJECT ask-then-write.
