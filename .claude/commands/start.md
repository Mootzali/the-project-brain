# /start — orient or bootstrap this business

You are in a `the-project-brain` clone. One brain = one business.

## Steps

1. Read `brain/MAP.md` + `brain/STATUS.md`. If `brain/HANDOFF.md` non-empty, read it.
2. Grep `TODO` in `brain/PROJECT.md`:
   - If TODOs remain → NEW business. Interview user, one question at a time:
     - One-line definition?
     - Who pays, why, how charged?
     - We do / explicitly DON'T do?
     - Current phase + links?
     Then fill PROJECT.md, update STATUS.md (now/next), append first DECISIONS entry with rejected alternatives. Report what was written.
   - If no TODOs → RESUME. Report: "This is [X from PROJECT], stopped at [STATUS now], next [STATUS next]." Mention HANDOFF warm threads if any. Ask "Continue?" Do not start coding unprompted.
3. Never re-explain the business from scratch each time — PROJECT.md is truth, `/start` just loads it.

## Tone

Brief, factual. Name files you read.
