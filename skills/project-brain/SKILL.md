# project-brain skill — small team + full library

## Workflows (/start /update /handoff /decide /think /librarian /import)

### New business (`/start` fresh)
Interview → PROJECT.md → first DECISIONS (rejected + source) → STATUS. No code before PROJECT.

### Resume (`/start` later)
MAP + STATUS (+ HANDOFF) → "This is X, stopped at N, next Y" → ask continue. Never carry other-business memory.

### Update (`/update`)
Propose with reasons + what-NOT-updating. User approves per item. Tiered writes (STATUS/HANDOFF direct+announce, DECISIONS/PROJECT ask first).

### Handoff (`/handoff`)
STATUS overwrite → archive HANDOFF to `handoffs/<ts>.md` → fresh HANDOFF (unsettled only).

### Decide (`/decide`)
Gentle "does this count as decided?" → append with rejected + source + affects. Reversal = new entry.

### Think (`/think`)
Grep library/topics/DECISIONS → cited answer per claim + Gaps (stale/conflict/missing). Say unknown when unknown.

### Librarian (`/librarian`)
Provenance (source per fact?) → contradictions → inbox triage → hot/cold → lint-links → skillify repeats. Propose, user approves.

## Rules
- Inbox first, promote or drop. Inbox > 14d = debt.
- Wiki-link slugs only, `lint-links.sh` green.
- Own STATUS/HANDOFF only. In-place edits. Stage own hunks.
